# Portfolio Optimization using Python

This project focuses on portfolio optimization and financial data analysis using Python and quantitative finance techniques.

## Project Overview

The objective of this project is to:

- Analyze historical stock market data
- Calculate returns and risk metrics
- Optimize portfolio allocation
- Visualize portfolio performance
- Apply modern portfolio theory concepts

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- yFinance
- SciPy

## Features

- Stock data collection using Yahoo Finance API
- Daily return calculations
- Risk and volatility analysis
- Correlation matrix visualization
- Efficient portfolio optimization
- Portfolio performance comparison

## Example Workflow

1. Download historical stock data
2. Clean and process data
3. Calculate returns and covariance
4. Optimize portfolio weights
5. Visualize efficient frontier

## Future Improvements

- Sharpe ratio maximization
- Monte Carlo simulations
- Real-time market data
- Machine learning based predictions
